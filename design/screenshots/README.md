# Screenshots

Gallery images for the root `README.md`, captured from **the real built product** — the labelled
demo walked through every room by `scripts/capture-screens.mjs` (real Chromium, the app's own
doors and controls), not mockups and not the prototype.

Re-capture after any visual change with:

```bash
npm run build -w @company/web
node scripts/capture-screens.mjs
```

The set: `00` landing · `01` team · `02` tasks · `03` inbox · `04` conversations · `05` network ·
`06` world map · `07` settings · `13` history (light, English); `08`–`11` the dark and Arabic
passes; `12` a phone. Older prototype captures were retired when the product outgrew them
(2026-10-12).
